# Сроки до первой версии и риски (черновик, уточняется по замерам)

## Что входит в первую версию

Это предложение; объём утверждает владелец.

1. Сессии. Каждая сессия — своё `WKWebsiteDataStore(forIdentifier:)`, вкладки, адресная строка, история. Список сессий: создать, переименовать, удалить, экспортировать и импортировать куки.
2. Прокси на сессию: HTTP и SOCKS5 с паролем, без отката на прямое соединение. При добавлении — проверка: выходной IP, страна, работает ли.
3. Часовой пояс сессии по стране прокси. Это готовая правка из `PrivacyScripts`. Язык — по итогам замера `q2.language-at-runtime`.
4. Отпечаток: строка UA из готовых вариантов, канвас, WebGL и звук (выключить, настоящий, шум), переключатель WebRTC.
5. Режим Telegram: сессия сразу открывает Telegram Web со своим прокси.
6. Оплата: встроенные покупки (IAP) плюс принятие лицензии с сайта по правилу 3.1.3(b). Сервер лицензий уже умеет несколько устройств.
7. Проверки утечек в CI на симуляторе: стенд `ios-measure` превращается в регрессионный набор.

## Оценка (рабочие недели одного разработчика, знакомого с кодом macOS-версии)
