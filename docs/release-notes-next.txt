Earlier versions wrote the settings profiles give Safari's own services (AutoFill, Safari Suggestions, fraudulent website warnings and a few others) into the file ~/Library/Preferences/com.apple.Safari.plist. Safari itself does not read that file — it keeps its settings in its own container — so none of Safari's settings changed. This version takes those entries out of that file once, after the first unlock: only those that still hold the value an earlier version wrote; one changed since stays as it is, and nothing else in the file is touched.

Safari's window in each profile keeps its own layout now — the window's size and place, the sidebar and favorites bar, the start page's sections — in that profile's encrypted data, rather than in one file shared by every profile. After the update each profile opens once with Safari's default layout.

Sync can now go through your Lumen account: Settings → Sync → Lumen Account, offered while this Mac is signed in. Nothing to type — this Mac's own sign-in reaches the Lumen server, which keeps only what is encrypted on the Mac; Lumen for iPhone signed in to the same account connects to the same vault with your master password. When the server's copy is not the one this Mac last synced with — restored from a backup, or deleted on the account page — the next sync compares everything again and puts this Mac's data back, merging rather than overwriting; an object refused for the plan's space waits while the rest syncs.

Settings can be searched by what a setting is called, not only by the name of its page: type "zoom", "Dock" or "quit" above the sections and the page that holds it is listed with the setting it found; Return opens it, and the row is marked. The command palette (⌘K) finds single settings the same way. The Settings window now opens on the page you last used.

The menu bar has the app's everyday commands: Lock Vault (⇧⌘L), Check for Updates… and Account… in the Lumen menu; Proxies… (⇧⌘P) and Sync Now in File. Lock from the menu, the keyboard or the palette asks first while profiles are running and lists what it stops, as Quit does (Settings → Startup → Confirm quitting); the Lock button in the Profiles window works as before. Settings → Keyboard Shortcuts and Help now list every one of these keys.

Unlock with Touch ID. Settings → Security → Unlock with Touch ID (off by default; on a Mac with Touch ID): the vault opens with your fingerprint in place of the master password. Turning it on asks for the master password once. The password is still asked after the Mac restarts, after 14 days without typing it, when Touch ID does not recognise you, and to change it or show saved passwords — do not forget it, Touch ID does not replace it. What changes: while it is on, the vault's key is kept on this Mac behind its Touch ID, readable by Lumen only after your fingerprint and never leaving this Mac, instead of being in memory alone; turning it off, changing the master password or the Mac's fingerprints removes it.
