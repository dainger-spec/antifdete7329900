Earlier versions wrote the settings profiles give Safari's own services (AutoFill, Safari Suggestions, fraudulent website warnings and a few others) into the file ~/Library/Preferences/com.apple.Safari.plist. Safari itself does not read that file — it keeps its settings in its own container — so none of Safari's settings changed. This version takes those entries out of that file once, after the first unlock: only those that still hold the value PrivacyBrowser wrote; one changed since stays as it is, and nothing else in the file is touched.

Safari's window in each profile keeps its own layout now — the window's size and place, the sidebar and favorites bar, the start page's sections — in that profile's encrypted data, rather than in one file shared by every profile. After the update each profile opens once with Safari's default layout.
