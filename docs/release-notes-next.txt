Earlier versions wrote the settings profiles give Safari's own services (AutoFill, Safari Suggestions, fraudulent website warnings and a few others) into the file ~/Library/Preferences/com.apple.Safari.plist. Safari itself does not read that file — it keeps its settings in its own container — so none of Safari's settings changed. This version takes those entries out of that file once, after the first unlock: only those that still hold the value an earlier version wrote; one changed since stays as it is, and nothing else in the file is touched.

Safari's window in each profile keeps its own layout now — the window's size and place, the sidebar and favorites bar, the start page's sections — in that profile's encrypted data, rather than in one file shared by every profile. After the update each profile opens once with Safari's default layout.

Sync can now go through your Lumen account: Settings → Sync → Lumen Account, offered while this Mac is signed in. Nothing to type — this Mac's own sign-in reaches the Lumen server, which keeps only what is encrypted on the Mac; Lumen for iPhone signed in to the same account connects to the same vault with your master password. When the server's copy is not the one this Mac last synced with — restored from a backup, or deleted on the account page — the next sync compares everything again and puts this Mac's data back, merging rather than overwriting; an object refused for the plan's space waits while the rest syncs.

A vault you already have can be brought to a Mac that has none — a new Mac, or one whose disk was erased. On the first launch's master-password screen choose "I already have a vault": from your Lumen account (this Mac is already signed in, so the account's vaults are listed by when each was made and last changed), from a sync folder, or from a server of your own (its address, token and the vault's ID, now shown under Settings → Sync). Type that vault's master password and its profiles come down with their settings, proxies, passwords, bookmarks, history and cookies; this Mac then goes on syncing that same vault. Nothing is changed where the vault is kept, and nothing on the Mac counts as a vault until all of it has arrived: a download that is interrupted is kept and continued, not begun again. Through the account this needs a paid plan running, as sync does; the screen says so, and says when a new device has to wait. A second Mac can join a vault the same way: changes travel when each Mac runs Sync Now, and one profile should not run on two Macs at once. To replace a vault a Mac already made with the synced one, lock the app and choose "Forgot password…" — that vault is moved aside, not deleted — and then "I already have a vault".
