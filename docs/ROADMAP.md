## Сделано и работает

- **Подпись и заверение Apple.** `scripts/release.sh`: сборка → подпись Developer ID → заверение →
  архив → подпись архива. Заверенный выпуск 0.1.1 — 3 ноября (`scripts/build-app.sh`).
- **Выпуски приложения.** К 5 ноября вышла 0.1.3 (README сайта, «Случай, 5 ноября 2026»).
  Номер последнего выпуска — не проверено.
- **Автообновление.** Свой установщик, подписанная лента (`docs/UPDATES.md`).
- **Сервер аккаунтов.** На сервере — выпуск `v2026.11.09.2` с 9 ноября
  (`lumen-api-server/docs/RELEASES.md`). Порядок выкладки с репетицией на копии боевой базы и
  ступенями отката — `docs/DEPLOY.md` там же.
- **Оплата.** Криптовалюта через NOWPayments; СБП и карта через BigPay. Покупка с аккаунтом и без
  регистрации (ключ `LMK-…`).
- **Лицензии в приложении.** Вход или ключ, подписанный документ о правах, 4 дня без сети и 3 дня
  отсрочки, затем «только экспорт» (`docs/LICENSING.md`).
- **Сайт.** Опубликован на Cloudflare Pages; страницы загрузки сверяются с выпуском каждые шесть
  часов (`lumen-site/.github/workflows/release-drift.yml`).
- **Минимальная macOS — 26** (`Resources/Info.plist`).
- **CI.** Быстрый конвейер на каждый push и полный раз в сутки (`docs/CI.md`).

## 1. Порядок в репозитории приложения

### 1.1 Один ствол

Ветка по умолчанию `claude/macos-privacy-browser-prototype-0ns2oj` отстала от ствола на несколько
сотен коммитов. Открыты и не слиты четыре запроса на слияние (#1–#4), веток больше ста тридцати,
большинство — одноразовые `measure-*`.

Готово, когда: ветка по умолчанию — ствол; каждый из #1–#4 слит или закрыт с причиной; ветки
`measure-*`, чьи замеры записаны в документах, удалены.

### 1.2 Приложение для iPhone

`claude/ios-app` расходится со стволом с 7 ноября в обе стороны. В списке от 30 октября iPhone
стоял «после запуска».

Решает владелец: вести его в стволе или отдельным продуктом со своим графиком.

Готово, когда: решение записано здесь, и ветка либо слита, либо названа самостоятельной.

- **Удалённый прокси на macOS 27** не измерен: основной путь проверен там только с прокси на этом
  же Mac.
- **Сертификаты (AIA/OCSP), пункт 3.** Закрыт в коде после повторного открытия в прогоне 413;

  запрещённых; поисковые подсказки при наборе.

Готово, когда: у каждого пункта стоит номер прогона, где он измерен, или причина, по которой его
измерить нельзя.

## 3. Зависимость от Safari

Окно профиля — код Safari, вызываемый по именам (`SafariChrome.swift`, `ProfileNetworkGuard.swift`).
Обновление Safari может сломать его без изменения нашего кода.

Готово, когда: названо, какой прогон на какой версии Safari проверяет окно профиля до того, как
обновление дойдёт до покупателей, и что делает приложение, если Safari новее проверенной.
Сейчас — не проверено.

## 4. Сервер

Из `lumen-api-server/README.md`, «Что осталось», и `docs/RELEASES.md`.

- **Очередь тарифов** (более дешёвый тариф начинается после более дорогого, миграция `00019`) —
  код в ветке, выпуск не собран.
- **Защищённость машины** — находки аудита 2 ноября (`docs/HOST_SECURITY.md`) чинятся на сервере
  по слову владельца.
- **Синхронизация** — четыре вопроса владельцу (`docs/SYNC_SERVER.md`, 10–13).
- **Клиент синхронизации в приложении** — долг этого репозитория по `docs/CONTRACT.md` §16:
  поколение данных, ответы 413 и 507 откладывают один объект, конверт постоянного размера.
- **Копии** — полные; когда данных синхронизации станет больше 1 ГБ, нужен непрерывный архив
  журнала PostgreSQL.
- **Квитанции PDF** — в кабинете нарисованы, сервер их не делает.
- **CryptoBot** — у магазина BigPay не включён.
