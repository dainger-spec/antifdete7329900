## 2. Утечки: что не закрыто измерением

Из `docs/LEAK_AUDIT.md`.

- **Удалённый прокси на macOS 27** не измерен: основной путь проверен там только с прокси на этом
  же Mac.
- **Сертификаты (AIA/OCSP), пункт 3.** Закрыт в коде после повторного открытия в прогоне 413;
  контрольный запрос перехват не видел, поэтому доказательство неполное.

  WebTransport; сервис-воркер удалённого HTTPS-сайта; частные сети 192.168/16 и 172.16/12;
  общие для процессов профилей хранилища Foundation; список разрешённых служб XPC вместо списка
  запрещённых; поисковые подсказки при наборе.

Готово, когда: у каждого пункта стоит номер прогона, где он измерен, или причина, по которой его
измерить нельзя.

## 3. Зависимость от Safari

Окно профиля — код Safari, вызываемый по именам (`SafariChrome.swift`, `ProfileNetworkGuard.swift`).
Обновление Safari может сломать его без изменения нашего кода.

Готово, когда: названо, какой прогон на какой версии Safari проверяет окно профиля до того, как
обновление дойдёт до покупателей, и что делает приложение, если Safari новее проверенной.
Сейчас — не проверено.

## 4. Сервер

Из `lumen-api-server/README.md`, «Что осталось», и `docs/RELEASES.md`.

- **Возможности тарифа** (`features` в документе о правах: автоматизация — в «Профессиональном»,
  «Команде» и пробном периоде) — выпуск `v2026.11.10` собран, выкладка ждёт согласия владельца.
  Приложение не выпускается с автоматизацией по тарифу, пока сервер не подписывает `features`.
- **iPhone** — `platform`, предел телефонов, бесплатный уровень в документе: в работе, следующий
  выпуск (`docs/IPHONE.md`, решено 9 ноября).
- **Защищённость машины** — находки аудита 2 ноября (`docs/HOST_SECURITY.md`) чинятся на сервере
  по слову владельца.
- **Клиент синхронизации в приложении** — долг этого репозитория по `docs/CONTRACT.md` §16:
  поколение данных, ответы 413 и 507 откладывают один объект, конверт постоянного размера.
- **Копии** — полные; когда данных синхронизации станет больше 1 ГБ, нужен непрерывный архив
  журнала PostgreSQL.
- **Квитанции PDF** — в кабинете нарисованы, сервер их не делает.
- **CryptoBot** — у магазина BigPay не включён.
