# Lumen для iPhone — бриф дизайнеру

Нужен дизайн приложения Lumen для iPhone: все экраны и их состояния, на русском и английском, плюс
картинки для страницы в App Store. Приложение уже работает (SwiftUI), сейчас у него первый вариант
тёмного дизайна «Eclipse». Снимки всех экранов в их нынешнем виде приложены (папка «экраны»).

## Что за продукт

**Lumen — браузер изолированных сессий для тестирования.** Сессия — отдельный браузер внутри
приложения: свои куки, хранилище сайтов, кэш, вкладки, история, и при желании свой прокси (HTTP или
SOCKS5). Часовой пояс и язык страниц сессии следуют стране прокси. У каждой сессии свой постоянный
«профиль устройства», чтобы сайт видел разные сессии как разных посетителей.

Кто пользуется: QA-инженеры, разработчики, маркетологи, поддержка — те, кто проверяет сайты из разных
стран и под разными пользователями. Есть версия для Mac; аккаунт Lumen общий, сессии синхронизируются.

Ощущение, которое нужно: профессиональный инструмент, спокойный и точный, «как приложения Apple для
работы». Не игровое, не «хакерское».

### Слова, которых нигде не должно быть

Ни в интерфейсе, ни на картинках App Store, ни в примерах на макетах: антидетект, обход, фингерпринт,
подмена (отпечатка), мультиаккаунт, отпечаток, и по-английски antidetect, fingerprint, spoof, bypass,
multi-account. Говорим: сессии, изоляция, профиль устройства, тестирование. В приложении также нельзя
предлагать купить тариф, показывать цены или вести на страницу оплаты — только называть тариф, который
у человека уже есть (правила Apple и владельца). Это проверяется автоматически при сборке.

## Платформа и ограничения

- iPhone, только портретная ориентация, iOS 18 и новее (на iOS 26+ доступно стекло Liquid Glass).
- Два языка: русский и английский. Английские строки часто на 20–40 % короче, русские — длиннее:
  макеты нужны на обоих, с самыми длинными строками.
- Сейчас приложение всегда тёмное; сами сайты внутри показываются как есть (часто белые). Можно
  предложить и светлую тему — тогда для обеих.
- Системные элементы iOS (навигация, листы, клавиатура, меню, диалоги подтверждения) по возможности
  оставлять системными — так дешевле и надёжнее в работе.
- Иконки — SF Symbols, где можно. Свои — в SVG или PDF.
- Крупный текст (Dynamic Type) и VoiceOver должны работать: не завязывать вёрстку на точную длину строки.

## Экраны и состояния

Номера в скобках — файлы в папке «экраны».

### 1. Список сессий (главный экран)
- Пустой: «Сессий пока нет» + пояснение + кнопка «Новая сессия» (01).
- С сессиями (02, 04): карточка сессии — буква-аватар, имя, прокси или «Без прокси», страна выхода с
  флагом, когда открывали («Открывали 12 мин назад» / «Ещё не открывали»), описание, метки (#ads).
- Поиск по имени, описанию, меткам, прокси; «ничего не найдено» (03).
- Сверху: «Прокси», «Аккаунт», «+» (новая сессия).
- Над списком может быть уведомление аккаунта (оплаченный период заканчивается, часы iPhone
  расходятся с сервером, период закончился) — с крестиком «Скрыть» для некоторых.
- Долгое нажатие на карточку — меню: «Изменить», «Удалить».

### 2. Новая сессия / изменение сессии (лист)
- Поля: имя, описание, метки через запятую. «Сохранить». В режиме изменения — «Удалить» с
  подтверждением «Удалить сессию со всеми её данными?».

### 3. Браузер сессии
- Сверху: имя сессии и под ним строка выхода («🇩🇪 DE · Берлин» или «Без прокси»); строка адреса.
- Новая вкладка — стартовая страница: «Введите адрес или запрос», «Поисковик: Google» (10).
- Страница сайта (11, 31, 32) — сайт может быть белым, панели должны оставаться читаемыми.
- Нижняя плавающая панель: назад, вперёд, обновить, вкладки (число), история, настройки сессии.
- Состояние загрузки; страница, которая не загрузилась (мёртвый прокси — сайт не открывается, 38).

### 4. Вкладки (лист)
- Карточки вкладок с миниатюрой и заголовком, закрыть вкладку, «Новая вкладка», «Готово» (12).

### 5. История (лист)
- Список посещённых страниц; пустая — «История пуста» (14).

### 6. Настройки сессии (лист) (41)
- Прокси: выбор из списка или «Без прокси». Если сессия уже работала через прокси, снять его можно
  только через предупреждение «Профиль работал через прокси… сайты увидят настоящий адрес устройства»
  («Открывать без прокси» / «Оставить прокси»). На бесплатном уровне: «Прокси недоступны» + «Аккаунт».
- Часовой пояс и язык: «По стране прокси» / «Как у устройства», под ним итог (Europe/Berlin · de-DE)
  и пояснение мелким текстом.
- Профиль устройства: «Полный» / «Упрощённый» / «Свой»; у «Своего» — три переключателя
  (Канвас, WebGL, Звук: Выкл / Настоящий / Шум) и пояснение.
- Браузер (строка User-Agent): «Как Safari этого iPhone», версии iOS, «Своя» + поле.
- Поисковик: Google, DuckDuckGo, Bing…
- Сейчас это длинный список сегментов — главная зона для улучшения: понятнее объяснить, что важно.

### 7. Запертая сессия
- «Профиль заперт» + причина: доступ к прокси закончился / аккаунт заблокирован / сессия работала
  через прокси, а прокси сейчас нет (50, 76). Важно: это не ошибка, а защита — сессия не откроется
  напрямую, чтобы сайты не увидели настоящий адрес. Данные сохранены.

### 8. Прокси (список) (30, 37)
- Пустой: «Прокси пока нет».
- Строка прокси: имя, тип (HTTP / SOCKS5), адрес:порт · логин; итог проверки — «Работает · 🇩🇪 DE
  203.0.113.10» или «Недоступен: причина»; UDP: умеет / не умеет / не проверен; идёт проверка.
- Сверху «+».

### 9. Прокси: новый / изменение (лист)
- «Прокси одной строкой» — любой привычный вид, например `socks5://логин:пароль@адрес:порт`
  (обычно вставляют из буфера); «Тип» (HTTP / SOCKS5); «Название (необязательно)». При изменении
  пароль не показан («Строка без пароля оставит прежний»); «Удалить прокси». Проверка — при сохранении.

### 10. Аккаунт (лист) (62, 70, 71, 75, 80)
- Не вошли: «Вход не выполнен», «Войти»; блок «На этом iPhone»: Профили 2 из 2, Прокси: нет.
- Вошли: почта, «Код этого iPhone в кабинете: A5C4», «Обновить статус», «Выйти» (с подтверждением),
  «Синхронизация»; «Тариф: Профессиональный», шкала «Профили: 3 из 50», «Прокси: есть».
- Пробный период («Тариф: 7 дней бесплатно»), период заканчивается (жёлтым), период закончился,
  аккаунт заблокирован, достигнут лимит телефонов, iPhone отвязан на сервере (72, 73).
- Подпись: «Аккаунт Lumen — тот же, что в Lumen для Mac.»

### 11. Вход (лист)
- Почта, пароль, «Войти», «Забыли пароль?» (ведёт на сайт).
- Затем код из письма: поле кода, «Подтвердить», «Отправить код ещё раз», «Ввести пароль заново».
- Ошибки: неверный пароль, неверный код, слишком много попыток, нет сети.
- Проверка «я не робот» — лист со страницей сайта (74).
- Снимка формы входа в папке нет — тесты проходят её, но не снимают.

### 12. Синхронизация с Mac (лист) (77, 78, 79)
- Не включена на Mac; нет в тарифе («в пробном и платном тарифе»).
- Подключение: «Мастер-пароль» хранилища Mac, пояснение (нужен один раз, дальше Face ID), «Подключить».
- Подключено: «Хранилище подключено», «Синхронизировать», «Забыть хранилище», ход синхронизации.
- Сессии с Mac появляются в общем списке — возможно, им нужна пометка.

### 13. Прочее
- Иконка приложения (сейчас есть тёмная и «tinted» для iOS 18) — по желанию переделать.
- Экран запуска (сейчас просто фон).
