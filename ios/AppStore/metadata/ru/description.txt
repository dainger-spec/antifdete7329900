Lumen — браузер изолированных сессий для тестирования. Каждая сессия живёт отдельно от остальных: свои куки, своё хранилище сайтов, свой кэш, своя история и свои вкладки. Войдите в один и тот же сервис из пяти сессий — и сервис увидит пять разных посетителей.

СВОЙ ПРОКСИ У КАЖДОЙ СЕССИИ
• HTTP и SOCKS5, с логином и паролем. Пароль хранится только в связке ключей этого iPhone.
• Проверка прокси: работает ли, с какого адреса и из какой страны выходит, пропускает ли UDP.
• Сессия, которая работала через прокси, никогда не откроет страницу напрямую: если прокси недоступен, страница не загрузится, а ваш настоящий адрес останется при вас.
• Прокси можно сменить у открытой сессии — без перезапуска.

СЕССИЯ ГОВОРИТ НА ЯЗЫКЕ СТРАНЫ ПРОКСИ
• Часовой пояс и язык страниц следуют стране выхода прокси — или задаются вручную.
• Профиль устройства у каждой сессии свой и постоянный: сайт видит ту же сессию при каждом визите и разные сессии — разными.
• Строка браузера: Safari этого iPhone, одна из версий iOS или своя.

ВСЁ ДЛЯ РАБОТЫ
• Вкладки, история, поиск выбранным поисковиком.
• Описание и метки у сессий, поиск по имени, меткам и прокси.
• После перезапуска всё на месте: вкладки, куки, вход на сайтах.
• Синхронизация сессий с Lumen для Mac через аккаунт Lumen, со сквозным шифрованием.

ДЛЯ КОГО
Для тех, кто проверяет сайты и сервисы из разных стран и под разными пользователями: QA-инженеры, разработчики, маркетологи, команды поддержки.

ЧЕСТНО ОБ ОГРАНИЧЕНИЯХ iOS
• Сайты в Lumen не могут использовать service workers: они не работают без сети, а Telegram Web работает не полностью.
• Язык браузера один на всё приложение, а не свой у каждой сессии; язык страниц — свой.
• WebRTC в сессии с прокси выключен, иначе он ушёл бы мимо прокси. Звонки в браузере в такой сессии не работают.
• Фоновые скрипты сайта, загруженные отдельным файлом, видят настоящие параметры устройства.

Бесплатно — две сессии без прокси. Прокси, больше сессий и синхронизация — с аккаунтом Lumen.
