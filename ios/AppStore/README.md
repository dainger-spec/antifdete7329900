# Карточка Lumen в App Store

Всё, что заполняется в App Store Connect, кроме того, что может дать только владелец. Тексты лежат в
`metadata/` в раскладке, которую понимает `fastlane deliver` (можно и копировать руками, поле в поле).
`ios/scripts/release_rules.py` проверяет их в каждом прогоне CI: ни одного слова из запретного списка
владельца, ни одного предложения купить (правило Apple 3.1.1 запрещает и ссылки на покупку вне
приложения), длина каждого поля в пределах App Store Connect.

## Тексты

| Поле App Store Connect | Русский (`metadata/ru/`) | English (`metadata/en-US/`) |
|---|---|---|
| Название (30) | `name.txt` | `name.txt` |
| Подзаголовок (30) | `subtitle.txt` | `subtitle.txt` |
| Рекламный текст (170) | `promotional_text.txt` | `promotional_text.txt` |
| Описание (4000) | `description.txt` | `description.txt` |
| Ключевые слова (100) | `keywords.txt` | `keywords.txt` |
| Что нового | `release_notes.txt` | `release_notes.txt` |
| Заметки для проверки | — | `review_information/notes.txt` |

Ограничения iOS в описании — те же, что в `ios/LIMITATIONS.md` («человек должен узнать о них до
покупки»). Если название занято в App Store, запасные: «Lumen Sessions», «Lumen — сессии браузера».

## Что выбрать в App Store Connect

- **Категория:** основная — «Инструменты разработчика» (Developer Tools), дополнительная — «Утилиты».
- **Возрастной рейтинг:** в анкете «Неограниченный доступ к интернету» — **да** (это браузер), всё
  остальное — «нет». Итог — 18+ (у любого браузера с открытым интернетом).
- **Приватность («Данные, которые собирает приложение»):**
  - Контактные данные → адрес электронной почты: связан с пользователем, для работы приложения, не для
    слежки.
  - Идентификаторы → идентификатор устройства: связан с пользователем, для работы приложения.
  - Больше ничего: история, куки и сессии лежат на iPhone; синхронизация шифруется на устройстве, сервер
    её не читает — такие данные Apple собранными не считает. Отслеживания (tracking) нет.
  - Так же записано в манифесте приватности приложения (`ios/Lumen/Resources/PrivacyInfo.xcprivacy`) —
    ответы должны совпадать.
- **Шифрование (export compliance):** в приложении `ITSAppUsesNonExemptEncryption = false`, App Store
  Connect вопрос не задаст. Это верно, если стандартное шифрование (HTTPS системы и AES-GCM хранилища
  синхронизации, общий код с Mac) подпадает под исключение. Ответ надо сверить с тем, что отвечали для
  Mac, или с юристом — до первой отправки.
- **Цена:** бесплатно. Покупок внутри приложения нет.

## Что даёт только владелец

1. **Ссылки:** политика приватности (обязательна), поддержка (обязательна), сайт (по желанию). Нужны
   страницы на lumenbrowser.io; когда будут — `metadata/ru/privacy_url.txt`, `support_url.txt` и то же в
   `en-US/`.
2. **Copyright:** «2026 <владелец>».
3. **Для проверяющих Apple** (App Review Information, не в репозиторий — он публичный): адрес и пароль
   тестового аккаунта с оплаченным тарифом и рабочий прокси (строкой `socks5://логин:пароль@адрес:порт`).
   Без них проверяющий увидит только бесплатный уровень.
4. **Контакт для проверки:** имя, телефон, почта.

## Риск: правила Apple об оплате

Тарифы Lumen покупаются на сайте, в приложении их нет. Apple обычно требует, чтобы платные возможности
приложения продавались и через покупки внутри приложения (правило 3.1.1). Исключение, на которое мы
опираемся, — 3.1.3(f): бесплатное приложение-спутник платного веб-сервиса, без покупок внутри и без
призывов купить где-то ещё. Приложение и карточка этому следуют (правило 5 владельца проверяется в CI).
Но решение за проверяющим: возможен отказ с требованием добавить покупки внутри приложения. Тогда
варианты — добавить подписку через App Store (комиссия Apple 15–30 %) или оставить на iPhone только то,
что не продаётся. Стоит решить заранее, какой путь выбираем.
