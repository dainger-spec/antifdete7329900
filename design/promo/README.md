# Рекламный ролик Lumen, 75 секунд

`lumen-promo-ru.mp4` — 1920 × 1080, 60 кадров в секунду, H.264 High, BT.709, **без звука**. Весь текст — в кадре,
анимированными титрами.

Стиль — наш: интерфейс приложения в дизайне «Затмение» (утверждён 1 ноября: монохромный почти-чёрный, контурные
кнопки, свет затмения в углах окна, цвет профилей — `Theme.swift`, `EclipseLight.swift`, `docs/DESIGN.md` на стволе)
и подача сайта (`design/site/spec.md` на `claude/site-prototype`): двухтонные заголовки — белый, затем серый, слова
выходят из размытия, свет и стекло, один синий бренда. От ролика v4 (`design/site/video/` на `claude/site-design`)
взято то, что владелец одобрил: чёрный фон, свет, титры, монтаж; движения — одной плавной кривой, без остановок, с
размытием в движении на быстрых местах.

Главное в ролике — **Safari в каждом профиле** и **UDP / WebRTC через прокси**.

**Карточки карусели показаны как готовые функции — так решил владелец (12 ноября: «презентуй их как уже
сделанные»).** Для команды: в продукте сейчас из них есть одноразовые коды (`claude/eloquent-carson-vthr2g`,
12 ноября), перенос профиля файлом под паролем (экспорт `.pbprofile`), редактор сценариев (без записи мышкой) и
прогрев по расписанию; приложение для iPhone — на `claude/ios-app`. Остальное — план. Перед публикацией ролика
стоит сверить карусель с тем, что к тому дню вышло.

Playwright в карточке WebDriver не назван намеренно: он не подключается к `safaridriver` (у Playwright свой WebKit
и свой протокол). Selenium, WebdriverIO и любой клиент WebDriver — подключаются.

## Откуда цифры и утверждения

- **448, 31/31, 15/15, 10/10** — `design/site/copy/facts.mjs` (CI #388 и #385): 448 признаков страницы-зонда
  сравниваются с Safari раннера, заголовки, TLS и HTTP/2, геометрия окна.
- **«Мимо — ни одного пакета», «0 пакетов мимо прокси»** — `docs/TUNNEL.md` (самотест: видеозвонок внутри захвата
  каждого пакета раннера) и `facts.mjs` («egress check: nothing went around the profile's proxy»).
- **UDP / WebRTC** — `docs/TUNNEL.md`: ретранслятор TURN на 127.0.0.1 у каждого профиля, UDP ASSOCIATE через
  SOCKS5-прокси профиля, сетевая защита (content filter) не даёт процессам профиля соединиться мимо прокси.
  Подписи в кадре — строки приложения: «UDP работает», «Нет UDP», «UDP не проверен», «Через прокси, только
  ретранслятор», «Сетевая защита Lumen».
- **AES-256-GCM, Argon2id, 26 стран прогрева** — `facts.mjs`, `docs/ARCHITECTURE.md`, `WarmUpPreset.swift`.
- Слова «антидетект» в ролике нет — как на сайте.

Данные в кадре — образцы: адреса из документационных диапазонов (203.0.113.0/24, 198.51.100.0/24, 192.0.2.0/24),
домены `.example`, имена профилей и людей вымышлены.

## Где ролик расходится с продуктом

- Шрифт — Inter / Inter Display и JetBrains Mono: кадры сняты не на Mac, SF Pro там нет.
- Окна приложения нарисованы заново в HTML по `Theme.swift`, `ProfileListView.swift`, `ProfileInspector.swift` и
  строкам `Localizable.strings` ствола; снимков CI («ui-snapshots») в окружении, где делался ролик, получить
  нельзя.
- Окно Safari — упрощённая копия тулбара Safari 26 с меткой профиля.

## Как пересобрать

Нужны Node 22 и Playwright (Chromium), Python 3 с Pillow и NumPy, ffmpeg. Сеть не нужна.

```bash
# посмотреть любой момент: design/promo/stage/index.html?t=29.2  (← → — кадр, Shift — секунда, пробел — играть)
node design/promo/tools/frames.mjs 12.5,29.2              # кадры → design/promo/.cache/stills
node design/promo/tools/frames.mjs --sheet 0:75:1         # лист кадров раз в секунду

# ролик: кадры 3840 × 2160 (четыре пикселя на один), размытие в движении на быстрых местах
node design/promo/tools/capture.mjs --scale 2 --workers 4  # → design/promo/.cache/frames-2x
python3 -I design/promo/tools/compose.py design/promo/.cache/frames-2x design/promo/lumen-promo-ru.mp4

# черновик за пару минут: 1080p без размытия
node design/promo/tools/capture.mjs --scale 1 --no-blur --out design/promo/.cache/draft
python3 -I design/promo/tools/compose.py design/promo/.cache/draft design/promo/.cache/draft.mp4 --preset veryfast
```

Где что: `stage/engine.js` — время, кривые, появление слов; `stage/ui.js` — части приложения (окна, строки,
панель профиля, Safari, свет затмения); `stage/scenes/` — сцены по порядку; `tools/` — съёмка и сборка.
