# Синхронизация

Сервер хранит ваши данные только в зашифрованном виде: ключ не покидает ваших Mac, прочитать их можете только вы.

Команда занимает

53 МБ из 4 ГБ

Из них ваше — 42 МБ.

Место общее на команду, а хранилище у каждого своё: чужих хранилищ не видит никто — ни вы, ни другие в команде.

## Хранилища

- Хранилище 6f1c2a9e152 объекта · 42 МБ · изменено 12 минут назад

**Так сервер видит ваши данные Непрозрачные имена и размеры, крупные первыми.**

Имён профилей здесь нет: сервер их не знает. Они есть только в приложении на ваших Mac.

- `e1b04c77…5a9f3d02`3,6 МБ
- `3f9a07c1…b84e21c9`2,9 МБ
- `a41d9e30…07f5c2aa`1,7 МБ
- `c0e8b512…9d1a47f0`1,2 МБ
- Ещё 147 объектов
- `vault-header`0,6 КБ Заголовок хранилища: соль, параметры Argon2id и зашифрованный ключ, без секретов.

Какой Mac и когда синхронизировался, сервер не хранит — только когда хранилище менялось последний раз.

[Удалить данные синхронизации…]

Сервер удалит все зашифрованные объекты. Данные на ваших Mac останутся. Mac, на которых синхронизация включена, при следующей синхронизации выгрузят свои данные заново — чтобы на сервере ничего не осталось, сначала выключите синхронизацию на всех Mac.
