# Импорт cookies

Перенесите cookies из файла в профиль: из расширения браузера, инструмента автоматизации или экспорта другого браузера.

Обновлено 29 октября 2026 · Читать около пяти минут

## Какие файлы подходят

Lumen читает экспорт cookies в JSON и в формате Netscape `cookies.txt`.

| Формат | Откуда |
| --- | --- |
| JSON | EditThisCookie, Cookie-Editor |
| JSON | Puppeteer и Chrome DevTools, Playwright, Selenium |
| JSON | базы cookies Chrome и Firefox, JSON Lines |
| Netscape `cookies.txt` | curl, yt-dlp, расширения «cookies.txt» |

Файл — не больше 32 МБ.

## Как импортировать

1. В списке профилей откройте меню профиля **⋯** и выберите **Импорт cookies…**
2. Нажмите **Выбрать файл…** Lumen проверит его ещё до импорта: покажет, сколько cookies можно перенести, а какие нельзя — со строкой и причиной.
3. Нажмите **Импортировать cookies** — на кнопке будет их число.

Повреждённый файл не мешает импорту. Всё, что удалось прочитать, импортируется; испорченная запись стоит только себе.

## Запущенный и остановленный профиль

- **Запущенный** профиль получает cookies сразу.
- **Остановленный** — при следующем запуске, до загрузки первой страницы. До этого cookies ждут в хранилище зашифрованными.

Сеансовые cookies — те, у которых нет срока действия, — живут до остановки профиля, как в Safari.

## Что не импортируется

Отчёт перечисляет каждую пропущенную запись. Самые частые причины:

| Причина | Что делать |
| --- | --- |
| Срок действия истёк | Ничего: такой cookie сайт уже не примет |
| Зашифрованное значение из базы Chrome | Прочитать его может только Chrome — экспортируйте cookies расширением |
| Недопустимый домен | Домен — общедоступный суффикс вроде `co.uk` или пустой |
| Нарушены правила `__Host-` | Такой cookie должен быть Secure, только для хоста, с путём `/` |
| Повреждённые байты | Запись испорчена; остальные импортируются |

## Экспорт cookies

Обратная операция — **⋯ → Экспорт cookies…** Все cookies профиля, включая сеансовые, сохраняются в файл для других браузеров и инструментов: `cookies.txt` (Netscape), JSON для EditThisCookie и Cookie-Editor или JSON для Playwright и Puppeteer.

Файл экспорта не зашифрован. Тот, у кого он окажется, войдёт как этот профиль везде, где cookies — это вход.
