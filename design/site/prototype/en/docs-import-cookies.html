Importing cookies

Bring cookies from a file into a profile: from a browser extension, an automation tool, or another browser’s export.

Updated 29 October 2026About a five-minute read

Which files work

Lumen reads cookie exports in JSON and in the Netscape cookies.txt format.

FormatFrom
JSONEditThisCookie, Cookie-Editor
JSONPuppeteer and Chrome DevTools, Playwright, Selenium
JSONChrome and Firefox cookie databases, JSON Lines
Netscape cookies.txtcurl, yt-dlp, “cookies.txt” extensions

A file can be up to 32 MB.

How to import

  1. In the profile list, open the profile’s ⋯ menu and choose Import Cookies…
  2. Click Choose File… Lumen checks it before anything is imported: how many cookies can come across, and which cannot — with the line and why.
  3. Click Import Cookies — the button shows how many.

A damaged file does not stop the import. Everything readable is imported; a broken entry costs only itself.

Running and stopped profiles

  • A running profile gets the cookies at once.
  • A stopped one gets them at its next launch, before the first page loads. Until then they wait in the vault, encrypted.

Session cookies — those with no expiry — last until the profile stops, as in Safari.

What is not imported

The report lists every entry it skipped. The most common reasons:

ReasonWhat to do
ExpiredNothing: a site would not take it anyway
An encrypted value from Chrome’s databaseOnly Chrome can read it — export the cookies with an extension
Invalid domainThe domain is a public suffix such as co.uk, or empty
__Host- rules brokenSuch a cookie must be Secure, host-only, with the path /
Damaged bytesThe entry is broken; the others are imported

Exporting cookies

The other way round — ⋯ → Export Cookies… Every cookie of the profile, session ones included, goes into a file other browsers and tools read: cookies.txt (Netscape), JSON for EditThisCookie and Cookie-Editor, or JSON for Playwright and Puppeteer.

The export file is not encrypted. Whoever has it signs in as this profile wherever cookies are the sign-in.

Found a mistake, or is something missing? Write to us.
