Installing

  1. Drag it to Applications

    Open the downloaded Lumen.dmg and drag Lumen into Applications.

  2. Open it

    On the first launch macOS checks the signature and Apple’s notarization and asks whether to open an app downloaded from the internet. Click Open.

  3. Create a master password

    It encrypts everything Lumen keeps: the profile list, settings, passwords, history, bookmarks and website data. At least 10 characters. It cannot be recovered — write it down somewhere safe.

  4. Create a profile

    A name, a proxy and, if you like, a country for warm-up. Click Launch — that profile’s Safari window opens.

Signature and checksum

The signature proves we built the app and nobody changed it since. Check it with one command.

Signed by
Developer ID Application: company name (Team ID)
Notarized by
Apple Notary Service
Image SHA-256
published with every release
Terminal
# Signature and Apple notarization
$ codesign --verify --deep --strict --verbose=2 /Applications/Lumen.app
$ spctl --assess --type execute --verbose /Applications/Lumen.app
# Checksum of the downloaded image
$ shasum -a 256 ~/Downloads/Lumen.dmg

Expected: valid on disk, satisfies its Designated Requirement and source=Notarized Developer ID.

Something wrong?

macOS will not open the app

Check the signature with the commands above. If it fails, do not open the file — write to us.

A profile does not start

Usually the proxy: a wrong address, or it wants a password. The profile does not open sites directly in that case.

Forgot the master password

It cannot be recovered. The old vault can be set aside and a new one created.
