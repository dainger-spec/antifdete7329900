# Рекламный ролик Lumen, 30 секунд

`lumen-ru.mp4` (и `lumen-en.mp4`) — 1920 × 1080, 60 кадров в секунду, H.264 High, BT.709, звук AAC 256 кб/с, 48 кГц.
Каждый кадр снят в 4K и уменьшен до 1080p, поэтому края и текст гладкие; на быстрых движениях кадр собран
из нескольких мгновений затвора, как у настоящей камеры (размытие в движении).

Ролик собран из того же, что и сайт: MacBook из вступления (тот же рендер, но 16:9, 60 кадров в секунду и
с крышкой, которая открывается), сцены главной (переставлены для ролика и повёрнуты в 3D) и собственные кадры
ролика — имя в начале, сравнение с Safari, финальная карточка. Цифры — из `copy/facts.mjs`, тексты титров —
`copy/source/{ru,en}/film.mjs`.

Слова «антидетект» в ролике нет — по той же причине, что и на сайте (вопрос 5): эквайринг смотрит на
формулировки. Домена и срока пробного периода тоже нет: это ещё решения владельца (вопросы 1 и 3); когда они
будут, их можно добавить в финальную карточку одной строкой в `film.mjs`.

## Звук

Музыка и звуковые эффекты синтезированы скриптом `tools/film/sound.py` из синусов и шума — без сэмплов и чужой
музыки, поэтому ролик можно публиковать без лицензий. 120 ударов в минуту, аккорд на такт; склейки попадают
в доли, в момент падения прокси звук обрывается вместе со светом, финальный аккорд открывается на знаке.
Для публикации можно заменить на лицензированный трек: звук лежит отдельной дорожкой и пересобирается за
секунды.

## Как пересобрать

Нужны Node 22 с Playwright (Chromium), Python с Pillow и NumPy, ffmpeg. Сеть не нужна. Из `design/site/`:

```bash
node tools/film/hero.mjs              # MacBook, 265 кадров → video/.cache/hero (около 50 минут; продолжает с места остановки)
node tools/film/build.mjs             # сцена ролика → video/stage/{ru,en}.html
python3 -I tools/film/sound.py        # звук → video/.cache/sound.wav
node tools/film/capture.mjs ru        # кадры → video/.cache/frames/ru (около 10 минут)
sh tools/film/encode.sh ru            # ролик → video/lumen-ru.mp4
```

Посмотреть любой момент без съёмки: открыть `video/stage/ru.html?t=12.3` в Chromium или Safari (← → — кадр,
с Shift — секунда, пробел — проигрывание). Несколько кадров картинками: `node tools/film/capture.mjs ru --at 1,5.5,12 --out папка`.

Где ролик расходится с настоящим продуктом: шрифт — Inter Display (рендер идёт не на Mac, SF Pro там нет);
интерфейсы в кадре — те же нарисованные копии, что на сайте, с образцами данных приложения.
