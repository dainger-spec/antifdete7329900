# Рекламный ролик Lumen, 30 секунд

Сейчас актуальна **версия 4**:

- `lumen-v4-ru.mp4` — 1920 × 1080, 60 кадров в секунду, H.264 High, BT.709, звук AAC 256 кб/с, 48 кГц;
- `lumen-v4-ru-vertical.mp4` — то же для сторис: 1080 × 1920 (9:16).

Версия 4 — это первый ролик (`lumen-ru.mp4`) один в один по виду: чёрный фон, свет, шторки, титры, монтаж. Исправлено
то, что дёргалось. Раньше камера и повороты в 3D останавливались в каждой ключевой точке и снова разгонялись,
некоторые движения стартовали сразу с полной скорости, а нырки в окна обрывались на полном ходу. Теперь каждое
движение — одна плавная кривая через все точки, нырки разгоняются и мягко гасят скорость, а размытие в движении
(затвор 180°) есть на каждом движущемся кадре, не только на самых быстрых. По замеру межкадровые рывки в 3D-сценах
стали меньше на треть–половину.

Звук пока из первого ролика — он совпадает с монтажом. Его нужно заменить записанным треком со свободной
лицензией (раздел «Музыка»).

Вертикальная версия — те же кадры, каждый перекомпонован в 9:16: титры крупные и по центру, всё важное внутри
безопасной зоны сторис (около 250 px сверху и 340 px снизу закрывают имя аккаунта и кнопка); кадры, которые
ныряют один в другой, держат общую компоновку на время нырка.

Версии 2 (`lumen-v2-ru.mp4`, «Графит», `tools/film/`) и 3 (графитовая студия без свечений, в истории git)
владелец отклонил: обе вышли хуже первого.

Каждый кадр снят в 4K и уменьшен до 1080p, поэтому края и текст гладкие; на быстрых движениях кадр собран из
нескольких мгновений затвора, как у настоящей камеры. Ролик собран из того же, что и сайт: MacBook из вступления
(тот же рендер, 16:9, крышка открывается), сцены главной (переставлены и повёрнуты в 3D) и собственные кадры
ролика — имя в начале, сравнение с Safari, финальная карточка. Цифры — из `copy/facts.mjs`, титры —
`copy/source/{ru,en}/film3.mjs` (инструменты версии 4 лежат в `tools/film3/`).

Слова «антидетект» в ролике нет — по той же причине, что и на сайте (вопрос 5): эквайринг смотрит на
формулировки. Домена и срока пробного периода тоже нет: это решения владельца (вопросы 1 и 3); их можно добавить
в финальную карточку одной строкой в `film3.mjs`.

## Музыка

Нужен записанный трек со свободной лицензией для коммерческого использования, в том числе в рекламе. Характер:
уверенный, современный, с драйвом, около 120 ударов в минуту (у ролика сетка 120: каждая склейка на доле), с
чистым финальным ударом. `tools/film3/music.py` растягивает трек ровно до 120 (pitch не меняется), ставит его
такт на 2,0 с (экран просыпается), а финальный аккорд трека — на 26,0 с (половины знака сходятся), сводит до
−14 LUFS и проверяет, что склейки попадают в доли.

Скачать треки отсюда не удалось: сетевые настройки окружения закрывают pixabay.com, cdn.pixabay.com, mixkit.co и
assets.mixkit.co. Кандидаты с Pixabay (по описаниям, ещё не прослушаны):

1. «Powerful Stylish Stomp Rock (Lets Go)» — MarkJuly
2. «Modern Fashion Promo Rock — Painted Echo» — Coma-Media
3. «Drop It» — Coma-Media

Лицензия Pixabay разрешает коммерческое использование, в том числе в рекламе, бесплатно и без указания автора;
нельзя распространять сам аудиофайл отдельно от ролика, поэтому треки в git не кладутся (`video/music/` в
`.gitignore`). Некоторые авторы регистрируют треки в Content ID — сохраните ссылку на страницу трека, чтобы снять
претензию YouTube. У Mixkit лицензия запрещает эфир на ТВ и радио, поэтому он подходит только для интернета.

## Как пересобрать

Нужны Node 22 с Playwright (Chromium), Python с Pillow и NumPy, ffmpeg. Сеть не нужна. Из `design/site/`:

```bash
node tools/film3/hero.mjs                 # MacBook, 265 кадров → video/.cache/hero (около 50 минут; продолжает с места остановки)
node tools/film3/build.mjs                # сцена ролика → video/stage3/{ru,en}.html и вертикальная {ru,en}-v.html
node tools/film3/capture.mjs ru           # кадры 16:9 → video/.cache/frames3/ru (около 8 минут)
node tools/film3/capture.mjs ru --vert    # кадры 9:16 → video/.cache/frames3/ru-v (около 40 минут)
python3 -I tools/film3/music.py ТРЕК.mp3 --analyse                       # темп, такты, концовка трека
python3 -I tools/film3/music.py ТРЕК.mp3 --downbeat 12.3 --final 95.1 --name трек   # → video/.cache/music3/трек.wav
sh tools/film3/encode.sh ru --audio video/.cache/music3/трек.wav       # ролик → video/lumen-v4-ru.mp4
sh tools/film3/encode.sh ru-v --audio video/.cache/music3/трек.wav --out video/lumen-v4-ru-vertical.mp4
```

Посмотреть любой момент без съёмки: открыть `video/stage3/ru.html?t=12.3` (вертикальная — `ru-v.html`) в Chromium или Safari (← → — кадр,
с Shift — секунда, пробел — проигрывание). Несколько кадров картинками:
`node tools/film3/capture.mjs ru --at 1,5.5,12 --out папка`.

Где ролик расходится с настоящим продуктом: шрифт — Inter Display (рендер идёт не на Mac, SF Pro там нет);
интерфейсы в кадре — те же нарисованные копии, что на сайте, с образцами данных приложения.
